# FireNow video script — 2 min 48

## 0:00–0:18 — The context

**Screen:** globe, then a transition down to Landiras.

**Voice:** "12 July 2022. Landiras, in the Gironde. A wildfire becomes a command problem long before it becomes a statistic. FireNow lets you go back to H+2 and try a different strategy."

## 0:18–0:42 — The simulation

**Screen:** 2D view, active front, dominant cover, human exposure, the suppression block, fast playback.

**Voice:** "The front is simulated locally in the browser, off the main thread. Two-class Rothermel, standard fuel models, thirty-five real species, the DFCI track grid of the massif. And FireNow shows what it does not know: the banner says the engine is not calibrated, and the measured deviations are published in the repository."

## 0:42–1:00 — WebMCP, not a chat API

**Screen:** open "What the agent can do".

**Voice:** "The page never calls a language model. It exposes twenty-one domain-shaped WebMCP tools. The agent discovers them inside the already-authenticated page and shares exactly the same state as the officer. No API key, no OAuth, no separate MCP server."

## 1:00–1:28 — The request

**Screen:** ask the agent: "The wind shifts to north-west at 40 km/h. Give me two strategies to protect the village."

**Voice:** "The agent reads the situation, changes the scenario weather, queries the terrain and builds its plan freely. These writes are provisional: the vehicles, the control line and the evacuation zone appear as ghosts. Nothing is committed yet."

## 1:28–1:52 — The signature tool

**Screen:** compare_plans, three result cards.

**Voice:** "Compare plans runs the strategies inside the Worker and returns a verifiable result: area burned, head rate of spread and units consumed. The village shield holds the smallest area at T+6h, against the no-action baseline."

## 1:52–2:20 — A single approval

**Screen:** "Take the smallest result", then the plan review.

**Voice:** "Here is the one human interruption: the agent's intent, the readable diff, the map preview and the projected impact. Twenty-three units were staged without twenty-three confirmations. One click commits the batch."

**Action:** click "Commit".

## 2:20–2:38 — Traceability

**Screen:** plan applied, Undo banner, run the simulation.

**Voice:** "Every action is logged and reversible. The officer keeps the authority; the agent brings the speed of a staff."

## 2:38–2:48 — Closing

**Screen:** FireNow framing, map and WebMCP panel.

**Voice:** "FireNow. A map to decide with, an agent to explore with, a human to commit."
